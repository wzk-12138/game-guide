# 破局指南 · 游戏攻略站

一个暗色主题的游戏攻略内容聚合页面，单文件 HTML、零依赖。风格取自游戏 UI：荧光绿主色、网格背景、切角品牌标，Hero 区的手柄插图完全由 CSS 绘制，无任何图片资源。

**在线访问：<https://wzk-12138.github.io/game-guide/>**

## 页面结构

- **顶栏**：品牌标（切角方块 + 字母 P）、锚点导航（首页 / 热门攻略 / 技巧速递）、学号徽章。
- **Hero**：超大压缩字体标题「玩得更聪明，赢得更漂亮」+ 纯 CSS 手柄插图（GG 屏幕、方向键、按键点，硬阴影 + 倾斜构图）。
- **精选攻略**：三张攻略卡片——开局资源分配 / Boss 读招与反击节奏 / 四人队伍黄金配合，顶部可按分类筛选：全部 / 角色扮演 / 动作冒险 / 多人联机。
- **今日技巧**：内置 3 条技巧轮换，点击「换一条 →」切换。
- **页脚**：版权与设计署名。

## 功能特性

- **分类筛选**：攻略卡片按 `data-category` 过滤，点击即时显示 / 隐藏。
- **技巧轮换**：3 条技巧循环切换。
- **纯 CSS 插图**：手柄、屏幕、方向键、装饰菱形均由 CSS 绘制。
- **响应式**：视口小于 760px 时导航收起、Hero 改单列、攻略卡片改单列、插图缩放适配。

## 本地运行

单文件页面，双击 `index.html` 即可打开；或起一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
